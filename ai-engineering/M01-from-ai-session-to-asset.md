## 二、核心钩子（开头 300 字，可直接用）

> 你有没有这种感觉：每天和 Claude Code、各种 coding agent 干一堆活，会话记录堆了几百个，但真要写篇公众号，还是对着空白页发呆——"我到底有什么可写的？"
>
> 我前阵子干了件"轴"事：把这大半年和 AI 协作的 1000 多小时会话，系统性地扒了一遍，最后沉淀出 **1100+ 张可发布素材卡**和一套自动刷新机制。不是因为我有素材焦虑，而是我发现一个被所有人忽略的事实——
>
> **你每次让 AI 干活，它都在帮你留"素材痕迹"。** 提示词是你关心什么（选题方向），计划是方法论骨架，实际产出是硬事实证据。大多数人让这些痕迹烂在 `.claude` 目录里，而我把它变成了内容资产。
>
> 这篇文章不藏私，把整套方法论拆给你——三层采集、意图-证据落差识别、三级脱敏，照着做你也能搭一个属于自己的"素材永动机"。

## 三、正文大纲（6 段，每段给"论点 + 可展开素材"）

**① 痛点共鸣：素材荒是自媒体人的集体死穴**
- 论点：不是不会写，是「没东西写」；一手实践 ≠ 可发布内容，中间差一套提炼方法。
- 素材：引用你自己的转变（从"会话堆成山"到"卡片 1100+"）。

**② 核心洞察：任何 agent 都会留"三层痕迹"**
- 论点：提示词（意图层）/ 计划规格（框架层）/ 实际产出（证据层）。
- 图解1（**漏斗图**）：三层痕迹 → 可发布颗粒的提炼路径。

**③ 素材识别的本质：对比「意图层」和「证据层」的落差**
- 论点：用户想做的 vs AI 实际交付的，中间的落差、纠偏、意外数据 = 最好的内容钩子。
- 图解2（**双栏对比图**）：左"想做的" vs 右"交付的"，中间高亮落差。
- 金句：「灵感不是蹦出来的，是比对出来的。」

**④ 三层采集体系：复用脚本，不重复造轮子**
- 论点：L1 会话级广撒网打标 → L2 每日挑 1 高潜力选题 → L3 源目录拆细卡。
- 表格：每层对应脚本 / 入口 / 产出粒度 / 触发频率。
- 强调：自动化串起来后，每周日自动刷新，素材库"自己长大"。

**⑤ 安全红线：公开素材库如何不泄密（稀缺度最高的一段）**
- 论点：四级脱敏（低/中/高/极高）；incidents/memory 不读正文只抽主题；全局 sanitize 强制泛化。
- 图解3（**脱敏对照表 / checklist**）：每档适用源 + 泛化规则。
- 信任加成：敢讲"怎么安全发内部素材"的技术博主，专业度直接拉满。

**⑥ 彩蛋：这套框架也是复盘方法论（破圈钩子）**
- 论点：挖素材的方法 = 复盘的方法（意图 vs 证据落差 = 目标 vs 实际偏差）。
- 图解4（**双用途图**）：左"挖素材"、右"做复盘"，中间标注"同一套落差识别法"。
- 收尾呼应开头：现在我的会话记录不再是负担，而是「内容资产 + 项目黑盒记录仪」双产出。
