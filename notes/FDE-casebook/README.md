# FDE 实战案例集

行途收集的一线 FDE 落地案例库。目的有两个：一是给自己转行与第二曲线创业攒真实行业案例，看清现场到底在交付什么；二是把每个案例拆成可复用的方法与操作手册，下一个项目直接套用。

## 收录标准

- 只收一线从业者自述的真实项目案例，不收营销稿、二手转述和纯观点文；
- 每例必须读完原文再收录，不凭标题入集；
- 每例固定三件：案例拆解卡、成文（公众号稿）、操作手册；
- 第三方口径与本人经验严格分开标注，不把别人的案例写成自己亲历；
- 原文没给的数字（工具栈、周期、人力、效果）保持空白，不补、不猜。
