## 一句话

一家美妆企业的 FDE 落地中，舆情、竞品、复盘三个业务共用同一条数据清洗链路：先把小红书、抖音、视频号、微博等平台采回的多模态数据，洗成可查询、可追溯、按版本入库的可信数据——第一道交付是数据链路，不是模型。

## 原文结构（八步链路，精华转述）

定数据规范 → 保留原始内容 → 梳理数据关系 → 多模态归一 → 冲突和质量清洗 → 生成结构化数据 → 执行验收 → 按规则和版本入库。

- 定规范：先问「这批数据最后拿来干什么」，用途不同洗法不同；规范写清字段、关联、证据要求、可用范围、人工确认范围。典型判断：同一素材被十个账号发布，传播复盘全保留、自然讨论统计标同一重复组——先标记不删除，保住换口径的余地。
- 保留原始：原文、原图、原音、原视频、链接、发布时间、平台原始 ID 全留；清洗与识别结果只新增、不覆盖，出错时能定位错在采集、识别还是分析。
- 梳理关系：单平台保留 user_id、post_id、comment_id、parent_comment_id 四类 ID，主键用「平台名 + 平台原始 ID」；跨平台不凭昵称头像认人，无可靠主键和授权不拼个人轨迹。
- 多模态归一：文字处理乱码空白并保留原句证据；图片 OCR 与视觉识别并行且保留位置；音频统一格式采样率后 ASR 并带时间码；视频拆音轨与关键帧按时间合并，先低频抽帧定位再局部加密。工具组合（原文）：FFmpeg、PaddleOCR、Whisper、百度/腾讯云 OCR、腾讯云 ASR、火山引擎字幕；先 API 小批量验证，量稳后高频任务本地化，选型拿真实样本测方言、噪声、中英混合、竖屏字幕、截图小字。
- 冲突与质量：证据分级 A（官方字段/人工确认）→ B（原件可直接确认）→ C（多模型一致且上下文对上）→ D（单模型判断）→ E（关键词/规则候选）；冲突回原始证据核对，确认不了进待核队列、不参加精确数值统计；修正留原始值、修正值、证据等级、原因、复核状态、模型版本。重复内容归组不删除，统计时再定去重粒度；异常用多信号打风险分排序进人工复核，高分不直接删；记录状态四分：正常可用、重复关联、低质量待修复或隔离、高风险待复核。
- 结构化：五类字段（表达者与对象、提及的产品/部件/功能/服务、对象间发生了什么、观点/问题/意图、判断依据的位置）；规则与小模型管高频稳定任务，大模型管多语种、多对象、复杂指代、长文本，低置信进复核；大模型按固定 JSON 格式返回字段与证据。
- 验收与入库：入库前查原始完整性、评论回溯、识别结果位置、冲突状态、标签绑定、版本号；备人工确认样本与难例集，换规则换模型同批重跑；原始数据、处理结果、质量状态、版本信息分开保存。完整交付另含数据字典、关系说明、处理流程、质量报告、难例集、复核队列、版本记录。
- 评论区补充（Hanbin-AI，用户截图可见）：从不在数据源上改动，先采集，再按目的清洗，源数据供多项目以不同方式调用、互不影响——与原文「原始保留、只新增不覆盖」互证。

## 与行途经验的对照

| 维度 | 案例做法 | 行途既有经验 | 启发 |
|---|---|---|---|
| 工作顺序 | 规范与清洗在前，模型只是中间一环 | 写过「Harness 是规矩不是工具」、护栏三段论 | 规矩先行再添一现场证据：数据规范就是数据侧的护栏 |
| 裁决方式 | 冲突看证据等级 A–E，不看置信度 | 「完成认凭证不认自述」 | 同一条纪律的两个版本：交付认凭证，数据认原件证据 |
| 成本观 | 语义与大模型只处理复杂长尾，高频归规则和小模型 | 「省 token 的第一性原理：把不用推理的活从模型手里拿回来」 | 分工口径完全一致，可互相引用佐证 |
| 复用观 | 三个业务共用一条链路与一套入库数据 | 「一个 Skill 干所有事？我把它拆成了流水线」 | 共用层沉淀、上层取用，数据与 Skill 同理 |
| 验收观 | 难例集回归 + 版本分开保存 | 视频管线红线「技术指标通过 ≠ 实际合格，必须看一遍成片」 | 数据侧对应物是难例集：换任何部件都同批重跑 |
| 场景迁移 | 美妆多平台评论 | 本人本职电商技术，多平台评论/晒单/直播回放是同一类数据 | 整条链路可直接搬到电商店铺评论分析，迁移成本低 |

## 对第二曲线的价值判断

- 可迁移性：高。数据清洗是行业无关的现场能力，消费品、汽车、餐饮、旅游、舆情都能套同一条链路（原文亦如此定位）。
- 可沉淀资产：八步链路、证据分级表、四类 ID 关系、交付七件套清单——已沉淀为操作手册 v1.1（同目录），下个项目直接套用。
- 可报价性：适合按交付物报价（数据集 + 数据字典 + 质量报告 + 版本记录），不按人天卖时间，与此前 FDE 报价方法论素材卡判断一致。
- 局限：原文是一家之言且无量化效果，引用只引方法、不引效果；工具栈与人力按现场再定。
