# FDE 商业化实战拆解

行途收集的一线 FDE 从业者商业化自述拆解系列。FDE 实战案例集（`notes/FDE-casebook/`）收的是单个项目的交付案例；本系列收的是获客、成交、报价、规模化这类商业全流程复盘，两边互补：案例集回答「现场交付什么」，本系列回答「单子从哪来、怎么谈、怎么不亏」。

## 收录标准

- 只收一线从业者本人自述、读完原文再收录，不凭标题入集；
- 只存拆解卡与操作手册，不存、不转载原文全文，原文以链接为准；
- 作者自述的业绩、金额、身份一律标注「作者自述，未独立核验」，原文没给的数字不补、不猜；
- 第三方口径与行途本人经验严格分开标注；文内转引他人分享的部分单独注明出处层级；
- 拆出的报价、产品梯队只作行途定价时的参照锚，不是行途的对外报价。
